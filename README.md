# Student Performance Visualizer 📊

## About the Project
Student Performance Visualizer is a beginner-friendly Python project that displays student results using a colorful pie chart.

It shows how many students passed, failed, or were absent.

## Features
- Displays student performance in a pie chart.
- Shows percentage values for each category.
- Uses different colors for easy understanding.
- Highlights the fail category using an exploded slice.

## Technologies Used
- Python
- NumPy
- Matplotlib

## Installation

Install the required libraries:

```bash
pip install numpy matplotlib
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python main.py
```

## Example Data

| Category | Students |
|---|---:|
| Pass | 30 |
| Fail | 15 |
| Absent | 4 |
| **Total** | **49** |

## Output
The program generates a colorful pie chart showing the percentage of students who passed, failed, or were absent.

## Learning Purpose
This project demonstrates basic Python data visualization using Matplotlib.
